# Пробный прогон очереди в dev-браузере

Цель — увидеть, что расширение делает на живом hh.ru, ничего не отправив. «Отправить» не нажимать никогда.

1. **Сборка.** `npm run typecheck && npm test && npm run build`. Расширение читается только при старте браузера: после сборки браузер нужно перезапустить.
2. **Осмотр.** `node scripts/cdp-inspect.mjs`: вкладки и флаги.
   - CDP не отвечает → запустить `node scripts/dev-browser.mjs` в фоне (без вопроса).
   - Открыто что-то кроме стартовой страницы hh.ru → это может быть страница владельца: спросить, прежде чем закрывать или перезапускать браузер.
3. **Предохранители.** Флаги должны быть `queueRunning: false` и `dryRun: true`. Иначе — остановиться и сказать владельцу; самому пробный режим не включать и очередь не выключать (режим очереди переживает перезапуск браузера).
4. **Прогон.** `node scripts/cdp-queue-dry-run.mjs` (до 6 минут, запускать в фоне). Скрипт сам отказывается работать без пробного режима.
5. **Только форма.** Если нужен снимок открытой формы без прогона: `node scripts/cdp-inspect.mjs --form`.
6. **Итог.** Пересказать журнал панели и снимки форм (резюме, ответы анкеты, письмо); что проверено вживую, а что нет.

Капчу не обходить и не решать: увидел капчу — остановиться и сказать владельцу.
