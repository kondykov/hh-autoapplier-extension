## 5. Критерии приёмки

**#71**
- Из `Skipped` возможен возврат на оценку (`Failed` — нет, см. В2) с записью в истории; из отправленных статусов — `DomainException`, в API — 409.
- «Оценить заново» без настроенной LLM возвращает понятную ошибку и не меняет статус.
- Письмо и анкета после возврата соответствуют В3 и В4.
- Скрытая карточка отсутствует в списке по умолчанию, есть с фильтром, возвращается действием «Вернуть»; статус, история и `/api/stats` не меняются.
- Чужой отклик скрыть нельзя; в режиме `readOnly` кнопок нет.
- Сбор и импорт не создают скрытый отклик заново.

**#72 часть 1**
- `Junior` с `between1And3` доходит до LLM; с `noExperience` или стажировкой — `Skipped`; жёсткие стоп-слова работают как раньше.
- LLM получает требуемый опыт и не получает слова уровня в «не интересно».

## 7. Оценка версии

Текущие: расширение `0.6.14`, backend `0.1.3`. Расширение — патч, ориентир `~0.6`: один новый исход очереди. Backend — минорная, ориентир `~0.2`: новые поля, эндпоинты и миграции. Точные номера — в issue о релизе.

## 8. Риски и вне объёма

**Риски**
- Поля `workExperience`, `status.archived`, `closedForApplicants` и признак стажировки в коде и тестах не встречаются, известны только из issues (предположение до живой проверки; `status.archived` и `closedForApplicants` проверены 2026-11-10).
- Дополнительные запросы могут включить антибот: блокировка останавливает весь проход сбора.
- HTTP 5xx на странице вакансии не перехватывается отдельно и обрывает проход (`HhWebSource.cs:70`, ловится только `SourceBlockedException`). Для проверки архива это надо учесть.
- Текст работодателя — вход для инъекций и в извлечении: только типизированный ответ и проверка значений на сервере.
- Часть 2 #72 велика. Если затянется, её можно вынести в отдельный спринт без части 1.
- Старый `Skipped` «стоп-слово junior» после #72 сам не изменится (В2, В6).

**Вне объёма:** тестовые задания работодателей (#33), автоматический возврат из архива, извлечение просьб для отправленных откликов, правка данных на home-server, автоответы (#48).
