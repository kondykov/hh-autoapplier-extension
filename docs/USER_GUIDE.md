# Инструкция пользователя

Как поставить и каждый день пользоваться hh-autoapplier. Для разработчиков — [ARCHITECTURE.md](ARCHITECTURE.md), [BACKEND.md](BACKEND.md), API — `/scalar` на сервере.

## Что это и чего ждать

Полуавтоматические отклики на hh.ru:

1. **Сервер** (backend) раз в час собирает вакансии по вашим поискам с публичных страниц hh.ru и отбирает их по правилам.
2. **LLM** (по умолчанию Groq) оценивает каждую прошедшую правила вакансию под ваши резюме: подходит, сомнительно, не подходит. Подходящим пишет сопроводительное письмо, отвечает на анкеты работодателей.
3. **Вы** проверяете сомнительные: в веб-интерфейсе (раздел «Проверка») или кнопками в Telegram.
4. **Расширение** в браузере откликается на одобренные вакансии из очереди сервера: выбирает резюме, вставляет письмо и ответы анкеты, нажимает «Отправить».
5. **Ответы работодателей** расширение забирает из чатов hh.ru по кнопке «Автоответ»: статусы откликов, разбор приглашений и вопросов с черновиком ответа.

Риски: аккаунт hh.ru настоящий. Частые действия ведут к капче и блокировке; капчу инструмент не обходит — встаёт на паузу и ждёт вас. Автоматизация может противоречить условиям hh.ru: пользуйтесь умеренно.

## Установка

### Сервер

Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```powershell
cd server
copy .env.example .env
```

В `server/.env` задайте:

| Параметр | Что это |
|---|---|
| `POSTGRES_PASSWORD` | пароль базы — любой длинный |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | первый администратор (вы); пароль от 10 символов. После первого запуска смените пароль и очистите `ADMIN_PASSWORD` — в файле он лежит открытым текстом |
| `LLM_API_KEY` | ключ Groq: https://console.groq.com/keys (бесплатный тариф). Пусто — LLM выключена, вакансии идут в очередь по одним правилам |
| `LLM_DAILY_LIMIT` | сколько запросов к LLM в сутки (по умолчанию 300) |
| `TELEGRAM_BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather); пусто — без Telegram |
| `COLLECT_INTERVAL_MINUTES` | как часто собирать вакансии (по умолчанию 60) |

```powershell
docker compose up -d --build
```

Проверка: http://127.0.0.1:8080/health отвечает `{"status":"ok"}`. Сервер слушает только этот компьютер (`127.0.0.1`).

### Расширение

```powershell
npm install
npm run build
```

Загрузите папку `dist` в Chrome: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное». Или запустите тестовый браузер с расширением: `node scripts/dev-browser.mjs`. Войдите в hh.ru в этом браузере.

На страницах hh.ru справа появится панель **HH AutoApply** с версией в заголовке (например, `v0.6.3`). После `npm run build` браузер нужно перезапустить — по версии видно, загрузилась ли новая сборка.

Своё письмо по умолчанию (если сервер не прислал письмо LLM) можно положить в `letter.local.txt` до сборки — в git он не попадает — или вписать в панели.

## Первая настройка

Откройте веб-интерфейс http://127.0.0.1:8080/ и войдите email и паролем. Разделы: «Обзор» (счётчики по статусам), «Вакансии» (списки с фильтром и историей), «Проверка» (сомнительные: одобрить с правкой письма или отклонить), «Ответы работодателей» (разбор и черновики), «Поиски» и «Резюме» (формы), «Профиль» (пароль, токены расширения, Telegram, отчёт CSV), у администратора — «Администрирование» (пользователи, ручной запуск сбора и LLM) и выбор «Данные:», чтобы посмотреть чужие данные (только просмотр). Всё то же доступно через API в `/scalar` (http://127.0.0.1:8080/scalar) — ниже указаны запросы для справки.

### Связь расширения с сервером

Панель → «Сервер (backend)»: адрес `http://127.0.0.1:8080` и токен. Выпустите личный токен: «Профиль» → «Токены расширения» (или `POST /api/tokens` `{"name": "браузер"}` после входа по паролю) — значение `hh_…` показывается один раз, вставьте его в поле «Токен». «Проверить связь» — должно ответить «Связь есть».

### Резюме

`PUT /api/resumes` — по профилю на каждое ваше резюме на hh.ru:

- `name` — короткое имя (`.NET`);
- `match` — часть названия резюме на hh.ru, по ней расширение выберет его в форме отклика;
- `keywords` — направления (для правил);
- `summary` — опыт и навыки своими словами: LLM берёт факты **только** отсюда. Чего нет в `summary`, того не будет в письмах и ответах — пишите конкретно (стек, годы, проекты), без преувеличений;
- `letterTemplate` — шаблон письма: приветствие, подпись и контакты LLM сохранит дословно, середину напишет под вакансию.

На hh.ru у резюме должна быть видимость «Видно всем работодателям, зарегистрированным на hh.ru», иначе на часть вакансий не откликнуться.

### Поиски

`PUT /api/searches`, например:

```json
{"name": "dotnet", "query": "C# .NET", "area": "113", "extraParams": "work_format=REMOTE",
 "rules": {"excludeKeywords": ["junior", "1С"], "minSalaryRub": 200000, "allowedFormats": ["удалённо"]}}
```

Правила (`rules`): `includeKeywords` — нужно хотя бы одно из слов, `excludeKeywords` — ни одного; `allowedFormats` — допустимые форматы работы (часть текста формата на hh.ru: «удалённо», «гибрид»); `minSalaryRub`, `requireSalary` — зарплата; `skipWithTest` — пропускать вакансии с тестовым заданием; `minScore` — порог балла; `skipReview` — сомнительные по LLM сразу в очередь, без ручной проверки.

### Telegram

Если бот настроен: после входа по паролю `POST /api/telegram/link` → ссылка на бота с кодом (15 минут) → откройте её или отправьте боту `/start <код>`. Внизу чата — кнопки меню «Статус», «На проверке», «Помощь»; то же командами `/status`, `/review` (отклики на проверке с кнопками), `/help`. `/stop` — отвязать чат (бот спросит подтверждение). Под сообщением о приглашении или вопросе работодателя — кнопка «Обработано».

## Каждый день

### Сбор и оценка

Сервер собирает вакансии сам, раз в интервал. Оценка LLM, письма и ответы на анкеты идут в течение минуты после появления новых вакансий. Если вы нашли выдачу на hh.ru вручную — кнопка **«Выдачу на сервер»** на странице поиска отправит её карточки в поиск, указанный в панели («Поиск на сервере для выдачи»).

### Проверка сомнительных

Telegram: сообщение с кнопками «Одобрить» / «Отклонить»; если новых больше трёх — одна сводка, решать через `/review` или страницу. Раздел «Проверка» на http://127.0.0.1:8080/: письмо можно поправить перед одобрением.

### Отклики из очереди

1. Кнопка **«Из очереди»** в панели. По умолчанию включён **пробный режим** (галочка): расширение заполняет форму, но «Отправить» не нажимает — проверьте резюме, письмо и анкету.
2. Для настоящих откликов снимите галочку пробного режима (панель переспросит). Задайте **«Откликов за запуск очереди»** — после стольких очередь остановится сама (0 — без ограничения).
3. Остановить в любой момент — «Стоп очередь». Дневной лимит откликов — поле «Дневной лимит».

Анкеты: если у вакансии анкета без готовых ответов, расширение отправит вопросы на сервер, LLM ответит (обычно за минуту), и вакансия вернётся в очередь.

### Ответы работодателей

На странице чатов или «Откликов» hh.ru — кнопка **«Автоответ»**:

- статусы откликов на сервере обновятся (отказ, приглашение);
- приглашения и вопросы работодателей LLM разберёт и предложит ответ — в Telegram и в разделе «Ответы работодателей» на http://127.0.0.1:8080/ («Копировать и открыть чат», «Обработано»). Отвечаете вы сами, поправив `[заглушки]`;
- на новые отказы расширение отправит текст из поля «Ответ на отказ» — только там, где hh.ru разрешает писать (обычно после отказа переписка закрыта). В пробном режиме ничего не отправляется.

### Отчёт

Кнопка «Отчёт (CSV)» в панели — отклики из этого браузера; `GET /api/report?format=csv` — все отклики на сервере.

## Безопасность

- `server/.env` и токены никому не показывайте и не коммитьте. Утёк токен — отзовите: `DELETE /api/tokens/{id}`.
- Сервер доступен только с этого компьютера. Доступ снаружи — только через VPN (планируется, #6), портов в интернет не открывать.
- Расширение не вводит ваши пароли и не решает капчу.

## Проблемы

| Что видно | Что делать |
|---|---|
| «Капча: работа на паузе» | Решите капчу в браузере — расширение продолжит само. Сделайте перерыв: капча — знак слишком частых действий |
| «Поменяйте видимость резюме» | В настройках резюме на hh.ru — «Видно всем работодателям, зарегистрированным на hh.ru» |
| «Сервер недоступен» в панели | Запущен ли Docker и `docker compose up -d`; адрес в панели — `http://127.0.0.1:8080` |
| «Неверный токен» | Токен в панели отозван, с опечаткой или от другого сервера; выпустите новый (`POST /api/tokens`) |
| «Очередь пуста» | Нет одобренных вакансий: дождитесь сбора и оценки, проверьте сомнительные в разделе «Проверка», расширьте поиск |
| LLM не пишет письма | `LLM_API_KEY` пуст или исчерпан дневной лимит (`LLM_DAILY_LIMIT`) — администратору придёт сообщение в Telegram; продолжится сама на следующие сутки |
| «Форма отклика не открылась» | Вакансия в архиве или ведёт на сайт работодателя — она помечается неудачной, очередь идёт дальше |
| Новая версия расширения не видна | Перезапустите браузер после `npm run build` и сверьте версию в заголовке панели |
