## Блокеры и ограничения
- API hh.ru не используется (403 без токена); сервер читает публичные страницы hh.ru. Полный цикл в Docker проверен 2026-10-23: сбор → сохранение → оценка → очередь (5 вакансий по поиску «Blazor», удалённо)
- Антибот hh.ru при частых запросах с одного IP — сбор останавливается до следующего запуска
- Правила фильтрации в расширении работают только на выдаче; отфильтрованные не попадают в отчёт
- `Summary` и `LetterTemplate` у резюме не заполнены — владелец заполнит через `PUT /api/resumes` (без шаблона LLM пишет письмо сама, без подписи и контактов)
- В профиле браузера сохранено старое PHP-письмо — заменить в панели
- hh.ru на страницах отклика пишет «поменяйте видимость резюме» — и при выбранном резюме .NET (2026-10-25); проверить видимость обоих резюме, иначе отклик может не пройти
- Письма LLM: после строгого промпта и заполненных `Summary`/`LetterTemplate` (2026-10-25) выдумок имени, стажа и обязанностей нет; остаются вольности — сужение диапазона («до 15 мс» вместо 15–70 мс), «проектировал базы». Перед настоящей отправкой просматривать письма (пробный режим или `/api/queue`); переписать — `POST /api/llm/letters/reset` + `POST /api/llm/letters`
- Пробные прогоны очереди добавили вакансии в «Аутлайн» расширения (у них анкеты) — при желании очистить кнопкой «Очистить»
