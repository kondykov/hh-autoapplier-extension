## Проверено на живой странице (2026-10-24, без отправки откликов)
- Выбор резюме: на странице отклика список открывается, вариант выбирается, заголовок меняется (PHP → C# .NET)
- Капча: баннер и пауза панели включаются по `data-qa` капчи и снимаются после неё; селекторы совпадают с настоящей /account/captcha

## Не проверено на живых данных
- Режим «из очереди» с настоящей отправкой и отчётом статусов на сервер (проверен только пробный прогон: 6 вакансий, все с анкетами работодателя)
- Пробный режим на вакансии без анкеты (в очереди таких не было; покрыто тестом)
- Автопауза посреди работающего авто-режима (для этого нужен авто-режим с реальными откликами); логика покрыта тестами
- Выбор резюме во всплывающем окне отклика (проверена страница отклика; селекторы общие)

## Осторожно
- Авто-режим переживает перезапуск браузера (`running` в chrome.storage): перед открытием страницы вакансии в dev-браузере проверить, что на кнопке панели «Авто», а не «Стоп»

## Блокеры и ограничения
- API hh.ru не используется (403 без токена); сервер читает публичные страницы hh.ru. Полный цикл в Docker проверен 2026-10-23: сбор → сохранение → оценка → очередь (5 вакансий по поиску «Blazor», удалённо)
- Антибот hh.ru при частых запросах с одного IP — сбор останавливается до следующего запуска
- Правила фильтрации в расширении работают только на выдаче; отфильтрованные не попадают в отчёт
- В профиле браузера сохранено старое PHP-письмо — заменить в панели
- hh.ru на страницах отклика пишет «поменяйте видимость резюме» для резюме PHP — проверить видимость резюме
- Пробные прогоны очереди добавили 6 вакансий в «Аутлайн» расширения (у них анкеты) — при желании очистить кнопкой «Очистить»
